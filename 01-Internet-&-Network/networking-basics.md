# Networking Basics

A **network** is formed when multiple devices connect to communicate and exchange data.

Networks can range from small local environments such as a **LAN (Local Area Network)** to larger systems such as a **MAN (Metropolitan Area Network)** and **WAN (Wide Area Network)**.

## Key Networking Concepts

- **Switches** handle communication between devices within the same local network using **MAC addresses**.
- **Routers** direct traffic between different networks using **IP addresses**.
- IP addresses are mainly categorized into:
  - **IPv4**
  - **IPv6**
- An **Internet Service Provider (ISP)** provides access to the Internet.
- Residential networks commonly use:
  - **Modems** – connect the home network to the ISP.
  - **DHCP** – automatically assigns IP addresses to devices.
  - **NAT (Network Address Translation)** – allows multiple devices with private IP addresses to share a single public IP address.

## LAN, MAN, and WAN

| Network | Full Name | Description |
|---|---|---|
| **LAN** | Local Area Network | Covers a small area, such as a home, office, or school. |
| **MAN** | Metropolitan Area Network | Covers a larger area, such as a city. |
| **WAN** | Wide Area Network | Covers large geographical areas, potentially across countries or continents. |

## The Internet

The **Internet** is a massive global system of interconnected networks. It allows devices around the world to communicate and exchange information.

### Simple Flow

**Devices → Switch → Router → ISP → Internet → Other Networks → Other Devices**
